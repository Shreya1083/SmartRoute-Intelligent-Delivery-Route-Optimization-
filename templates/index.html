    Academic Concept Guide

    How the A* Search Algorithm Works

    A* is an informed (heuristic) search algorithm widely used in pathfinding, robotics, and logistics. It guarantees finding the shortest path efficiently by combining the actual cost traversed so far with an admissible heuristic estimate of the remaining distance.

    Evaluation Function

    f(n) = g(n) + h(n)

    The total estimated travel time of the cheapest solution passing through intersection n. The priority queue always selects and expands the node with the minimum f(n).

    Actual Path Cost

    g(n)

    The exact accumulated travel time (in minutes) taken to travel from the starting warehouse to node n along the current path. Increases as road travel times change due to traffic.

    Heuristic Function

    h(n) = √(Δx² + Δy²) / Vmax

    The estimated straight-line travel time from intersection n to the destination. Dividing Euclidean distance by maximum speed (Vmax = 40.0 units/min) ensures the estimate is admissible (never overestimates) and consistent (monotonic).

    Mathematical Guarantees: Admissibility and Consistency

    1. Admissibility Condition: h(n) ≤ h*(n)

    A heuristic is admissible if it never overestimates the true cost h*(n) to reach the goal. Since a straight line represents the shortest possible physical distance between two points, and no vehicle can exceed Vmax, the straight-line time estimate is always lower than or equal to the actual road travel time. Admissibility mathematically guarantees that A* will find the optimal path.

    2. Consistency (Monotonicity) Condition: h(n) ≤ cost(n, n′) + h(n′)

    A heuristic is consistent if for every node n and neighbor n′, the estimated cost from n to goal is no greater than the step cost from n to n′ plus the estimated cost from n′ to goal. By the triangle inequality of Euclidean geometry, straight-line distance satisfies this property. Consistency guarantees that once a node is expanded, its optimal path is found, eliminating the need to re-open closed nodes.

    3. How Route Optimization Works in SmartRoute

    1. Priority Queue Initialization: Push starting node with f(start) = 0 + h(start, goal).
    2. Expansion: Pop node current with smallest f(n). If it is the destination, terminate and reconstruct route.
    3. Neighbor Evaluation: For each neighbor, calculate tentative travel time g(neighbor). If faster than previously recorded, update parent pointer, calculate f(neighbor), and push to priority queue.
    4. Traffic Adaptation: When road costs increase, g(n) for congested paths increases, prompting A* to automatically steer through alternative, less congested corridors.
